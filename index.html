SelfTalkie 연결

같은 PC에서 SelfTalkie를 실행하고, 설정 → 쪼개라 연결에서 코드를 복사하세요. 완료 시각에 맞는 블록으로 보내며, 기존 일기는 유지됩니다.

이 기능을 추가한 뒤 완료·포기한 일부터 기록됩니다. 전송 실패 시 대기 목록에 남고, 다시 보내도 중복되지 않습니다. 처음 연결할 때 브라우저의 로컬 네트워크 접근을 허용해주세요.

동기화 설정 (GitHub Gist)

본인 GitHub 계정의 Personal Access Token(gist 권한)을 입력하세요. 이 브라우저에만 저장되고, GitHub API 호출 외에는 어디로도 전송되지 않습니다. Gist ID는 처음 ☁️ 올리기를 하면 자동으로 채워집니다 — 다른 기기에서는 그 ID를 여기에 붙여넣어야 같은 데이터를 받아올 수 있습니다.
